# 英词通

> 外研版初中、高中英语词汇听读与课文跟读工具  
> 作者：安得半日闲

英词通是一个纯静态的网页背单词应用，打开浏览器就能用。它把「看单词、听发音、跟读、课文朗读、每日打卡」放在一个页面里，默认使用紧凑布局，不标注中文谐音，适合日常碎片化复习。

## 功能

- **词库选择**：初中 2026 新版 5 册 + 旧版 6 册、高中 7 册，按教材、册、单元自由切换。
- **单词卡**：单词、音标、词性（中文标注）、中文释义、主题例句、例句翻译、放大后的逐词配图；新版初中使用真实配图，旧版/高中使用 Twemoji。
- **词形变化**：动词显示过去式/过去分词/现在分词/第三人称单数，名词显示复数，形容词显示比较级/最高级；可在设置里关闭。
- **字体大小**：小/中/大三档，默认中号；当前字号作为小号，方便一屏看更多词。
- **自动播放**：按单词页选择的朗读模式（英 / 英例 / 英中 / 英中例，默认英中）朗读；英中例按「英文 → 中文 → 例句」顺序。单词可重复 1/2/3 次，可开逐字母拼读，拼读风格可选标准或疯狂。播放范围可选「本单元」「整册连播（自动跨单元）」「学段连播（自动跨册）」。
- **英语发音**：新版七上内置 Aria / Jenny / Guy / Sonia 四套神经语音，默认 Aria，可在设置页切换并试听；单词、例句和字母拼读优先使用内置音频，浏览器系统英语声音作为兜底。
- **跟读练习**：点跟读按钮自动录音 5 秒、自动停止并回放；可在设置里开启浏览器识别评分，识别不可用时自动转录音，国内网络也能练。
- **课文跟读**：每个单元配一段主题短文，支持整段播放、逐句播放、逐句跟读、显示/隐藏译文；下方另附本单元例句跟读。
- **教材原文**：新版七上已收录 Starter 和 Unit 1–6 的主要阅读篇目，旧版收录七上 Module 1、八上 Module 1；可逐句朗读和跟读。未收录的单元会说明原因，并提供百度和 Bing 搜索入口。教材原文版权归原出版社，仅供个人学习。
- **记忆复习**：独立的复习页，提供今日待复习、错词本；默认「听音选义」，也可切换「看词选义」「看义拼写」；答对后按 1、3、7、14、30 天安排下次复习，答错会回到短间隔并进入错词本。
- **每日目标打卡**：设置每日学习词数（5/10/15/20/30），当天标记已学或完成自测达到目标后，打卡按钮才会启用；同时显示连续天数、累计天数、月历和里程碑徽章。
- **打卡分享**：根据当天实际学习内容生成口语化总结、今日收获和针对性鼓励，支持复制文案、系统分享和保存分享图，也可以「换个说法」。
- **学习进度**：每个单词可标记「已学」，按单元统计进度，记录保存在浏览器本地。
- **独立设置页**：紧凑布局、字体大小、例句翻译、词形变化、英语声音、朗读风格、播放范围、播放间隔、每日目标、跟读评分、重置记录等统一放在设置页；主页面只保留学习内容。
- **PWA**：支持添加到手机主屏幕，Service Worker 缓存静态资源，可离线打开页面；语音识别仍需网络和麦克风权限。
- **响应式**：手机和电脑都能使用，播放条会固定在底部。

## 本地预览

这是一个纯静态项目，不需要安装依赖。由于浏览器的麦克风权限和语音识别通常要求安全上下文（`https` 或 `localhost`），建议不要直接双击 `index.html`，而是启动一个本地服务器：

```bash
# 在项目目录下
python -m http.server 4173
```

然后打开：

```text
http://127.0.0.1:4173/
```

也可以用 VS Code 的 Live Server，或任意静态文件服务器。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `english-daily`）。
2. 把本目录下的文件上传到仓库根目录，确保 `index.html` 在根目录。
3. 进入仓库的 **Settings → Pages**。
4. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。
5. 等待一两分钟，访问 `https://你的用户名.github.io/english-daily/`。

如果本机有 Python 和 GitHub token，也可以直接用 API 上传：

```bash
set GITHUB_TOKEN=ghp_你的临时token
python scripts/upload_github.py --repo english-daily --pages
```

脚本会读取 token、创建公开仓库、上传全部文件，并尝试开启 Pages；token 不会写入文件。没有 `repo` 权限的 token 会失败。

GitHub Pages 默认提供 HTTPS，麦克风跟读功能可以正常申请权限。

## 安装为 PWA

部署到 GitHub Pages 后，用手机浏览器打开站点：

- **Android Chrome**：右上角菜单 →「添加到主屏幕」/「安装应用」。
- **iPhone Safari**：分享按钮 →「添加到主屏幕」。

`manifest.webmanifest` 提供应用名称、图标和启动方式；`sw.js` 会缓存页面、CSS、JS 和词库，断网时仍能打开已加载的页面。修改静态文件后请同步修改 `sw.js` 里的 `CACHE_NAME`（例如 `english-daily-v1.5.1`），否则已安装用户可能继续使用旧缓存。

> GitHub Pages 地址示例：`https://你的用户名.github.io/english-daily/`。

## 怎么记更牢

背单词最容易犯的错，是反复看、反复抄，却没有真正回忆。英词通的复习页围绕几个记忆原则设计：

1. **主动回忆**：先看英文想中文，或看中文拼英文，想不起来再看答案。检索本身会加强记忆。
2. **间隔重复**：答对后不是永远不再看，而是在第 1、3、7、14、30 天再次出现；答错的词回到短间隔，并进入错词本。
3. **语境和声音**：核心词配主题例句和插画，朗读、跟读同时调动声音和场景。扩展词没有例句时，至少用发音和释义建立第一层联系。
4. **少量多次**：每天 10–15 个词、10 分钟左右，比一次背一小时更稳。复习页的「开始一组」默认 10 个词。
5. **输出练习**：跟读、拼写、听音选义都是输出；输出比单纯输入更容易暴露“以为会了”的词。

建议的使用顺序：先看单词和例句 → 听两遍、跟读一遍 → 用「听音选义」自测 → 第二天用「看义拼写」或「看词选义」复习 → 错词只复习错词。

## 浏览器与语音说明

- **推荐浏览器**：Edge 或 Chrome。两者对 Web Speech API（语音合成 + 语音识别）支持最好。
- **朗读声音**：新版七上优先使用内置的 Aria / Jenny / Guy / Sonia 神经语音，默认 Aria，不依赖系统英语语音。其他单元会回退到系统英语声音；设置里可优先选择名称带 `Natural` / `Neural` 的声音。
- **如果设置里显示“系统默认英语声音”**：说明当前系统没有向浏览器暴露英语语音；新版七上仍会用内置音频，其他单元可以在 Windows 的「设置 → 时间和语言 → 语音」安装英语语音包，或改用 Edge。
- **跟读识别**：需要浏览器支持 `SpeechRecognition`，并允许麦克风权限。Chrome / Edge 支持较好；Firefox 等浏览器可能只支持朗读、不支持识别评分。
- **自动播放**：浏览器通常要求用户先点击一次页面才能播放声音。点击「自动播放」或任意 🔊 按钮即可解锁。
- **iOS Safari**：语音合成和自动播放行为受系统限制，建议在电脑端 Edge / Chrome 使用完整功能。

核心词使用 7 个字段，扩展词使用 4 个字段：

```js
// 核心词（js/data-*.js）
["classmate", "/ˈklɑːsmeɪt/", "n.", "同班同学",
 "Tony is my new classmate.", "托尼是我的新同学。", "🧑‍🎓"]

// 扩展词（js/extra-*.js）
["curious", "/ˈkjʊəriəs/", "adj.", "好奇的"]
```

扩展词文件的结构：

```js
window.YCT_EXTRA = window.YCT_EXTRA || {};
window.YCT_EXTRA["j7a"] = window.YCT_EXTRA["j7a"] || {};
window.YCT_EXTRA["j7a"]["m1"] = [
  ["from", "/frɒm/", "prep.", "来自"],
  ["America", "/əˈmerɪkə/", "n.", "美国"]
];
```

应用启动时会把 `YCT_EXTRA` 合并到对应单元，自动跳过与核心词重复的条目。扩展词的例句来自 `js/examples-*.js`，图标来自 `js/icons-*.js` 或 Twemoji；单词卡会显示「扩展」标记。

每个核心单词使用一个数组表示：

```js
["classmate", "/ˈklɑːsmeɪt/", "n.", "同班同学",
 "Tony is my new classmate.", "托尼是我的新同学。", "🧑‍🎓"]
```

字段依次为：

1. 单词
2. 音标
3. 词性
4. 中文释义
5. 英文例句
6. 例句中文翻译
7. 插画图标（emoji）
8. 可选：本地配图路径（如 `icons/words/j7a26/s/01.jpg`，新版初中使用）

一个单元的结构：

```js
{
  id: "m1",
  name: "Module 1",
  title: "My classmates",
  words: [ /* 单词数组 */ ],
  passage: {
    en: "英文跟读短文",
    zh: "中文翻译"
  }
}
```

新增教材或单元时，复制一个单元对象，修改 `id`、`name`、`title`、`words`、`passage`，再把它加入对应册的 `units` 数组即可。若新增了词库文件，记得在 `index.html` 底部按顺序引入。

## 常见问题

**Q：点击播放没有声音？**  
先点击页面任意位置再试；检查系统音量、浏览器标签页是否静音；在设置里试听当前声音。

**Q：跟读总是提示没听清、声音大一点？**  
这通常不是音量问题，而是浏览器的语音识别服务不可用（国内网络访问 Google 识别服务、麦克风未授权、或浏览器不支持）。现在连续失败会给出明确提示，并高亮「录音回放」按钮；可以直接录音后回放，对比自己的发音。想要识别评分，请使用 Chrome / Edge，通过 `localhost` 或 `https` 打开，并允许麦克风权限。

**Q：打卡按钮为什么是灰的？**  
打卡不再只是点一个对号。每天的「今日学习目标」达到后按钮才会启用；去单词页标记已学，或到复习页完成一组自测，都会计入今日词数。目标可以在设置页改成 5/10/15/20/30 个词。

**Q：扩展词是怎么来的？**  
扩展词来自公开的教材单元词表（如朗读宝等公开教学资料），按册、单元整理；它们的例句是学习用自造句，不是教材原句。不同年份、不同印刷批次的教材可能有差异，建议以学生手上的教材为准。

**Q：词形变化准确吗？**  
动词过去式、名词复数、形容词比较级由规则生成，常见不规则词已单独收录，供学习参考；遇到不常见或特殊词形，请以词典为准。设置页可以关闭「显示词形变化」。

**Q：图片为什么有的是照片，有的是卡通图？**  
新版初中使用朗读宝公开页面的逐词配图，下载压缩后放在 `icons/words/`；旧版和高中使用与词义相关的 Twemoji 卡通图标。两者都按单词单独匹配，不再共用单元图标。图片版权说明见 `THIRD_PARTY_NOTICES.md`，公开分发前请确认授权。

**Q：教材原文都有吗？**  
新版七上已收录 Starter 和 Unit 1–6 的主要阅读篇目，旧版收录七上 Module 1、八上 Module 1，可以逐句播放和跟读。新版教材没有公开的电子文本，官方电子课本需要登录且不能直接复制，所以其余单元暂未收录，课文页会说明原因并提供百度/Bing 搜索入口。教材原文版权归原出版社，公开上传前请确认授权。

**Q：字号可以调吗？**  
可以。设置页提供小/中/大三档，默认中号；原来偏小的字号作为小号。字体大小会保存在本地。

**Q：词库完整吗？**  
当前有 18 册、135 个单元、约 5213 个词条，其中 2026 新版初中 5 册 31 单元 814 个词，旧版初中 6 册 62 模块，高中 7 册 42 单元。新版按 Unit 整理，旧版保留并标注「旧版」；不同年份、不同印刷批次的教材词表可能有差异，建议以学生手上的教材为准。发现漏词或错词时，新版改 `js/data-junior-2026.js`，旧版扩展词改 `js/extra-*.js`。

**Q：例句和课本不完全一样？**
